# Example Vaults

Three vaults, each about six weeks into a fictional project, show the protocols at work. Each README has a tour pointing to the files that show each protocol.

| Example | Project | What it shows |
|---|---|---|
| [Software](software/README.md) | **Brigade**, a shift-scheduling web app for small restaurants | Interviews overturn a technical decision and pilot data weakens a product rule. |
| [Business](business/README.md) | **Curbside Cycles**, a mobile bike-repair van | A pilot month replaces per-visit pricing with a membership. |
| [Creative](creative/README.md) | **Low Tide**, a short narrative puzzle game | Playtests shrink a branching story to fit a two-person team. |

All three start from the same [template](https://github.com/adamcee/agentic-vault/tree/main/template). Research in the examples is the fictional teams' own interviews, pilots, and playtests.
