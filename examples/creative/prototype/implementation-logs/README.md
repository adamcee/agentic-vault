# Implementation Logs

One file per ISO week that had a session, named `YYYY-Www.md` (for example `2026-W42.md`), with a section appended by each session that changes the vault. Past weeks are never edited; corrections go in the current week as dated notes ([[vault-guide/session-logs]]).

## Section Format

```
## YYYY-MM-DD (agent, session type)
- What changed, with [[wikilinks]].
- Decisions, reweaves, and action items routed to the ledger.
```
