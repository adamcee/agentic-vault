# Concepts

Each note defines one key term and links to where it's used. A concept note defines something that exists; proposals go in `ideas/`.

- [[concepts/parley]]: resolving an encounter by talking, offering an item, or shining the lantern.
- [[concepts/moon-shift]]: the change in path layout when the moon phase changes.
- [[concepts/waymark]]: a lantern post where paths meet, the one point on a route that never moves.
- [[concepts/sealed-letter]]: a letter Wren may open, with social consequences only.
- [[concepts/lantern-oil]]: the night's clock and currency.
- [[concepts/satchel-weight]]: the trade between carrying more and walking faster.
- [[concepts/postmark]]: a stamp for how a letter was delivered, and the progression system.
- [[concepts/letter-budget]]: the 120-word soft limit on a letter's body.
- [[concepts/handheld-floor]]: the minimum target of 30 fps at 800p on a handheld PC.
- [[concepts/vertical-slice]]: a short section of the game built to near-final quality.
