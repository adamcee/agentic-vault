# Full Day-Night Cycle

Add a daytime phase between nights, when Wren could walk around villages, talk to recipients face to face, and see the forest in daylight.

## Why It Came Up

Tomas asked early on whether players would tire of a game set entirely at night. Daytime scenes looked like a way to vary the mood.

## What Happened

- **Rejected on 2026-05-12.** Every background would need a day version as well as a night one, which doubles background art for a team with one artist. The decision came the same day as [[decisions/product/PDR-P005-painted-night-palette|PDR-P005]] set a limited, painted night palette.
- **The lore followed.** In canon, Hollowmere's paths connect the villages only after dark, so there is no reason to travel by day ([[world/hollowmere]]).
- **Scope.** It also keeps the game inside [[architecture/CONSTITUTION]] P4.
