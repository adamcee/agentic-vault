# Letter-Writing Minigame

Let Wren write short letters of Wren's own by choosing lines and phrases, then deliver them like any other letter. Recipients would answer differently depending on what Wren wrote.

## Why It Came Up

The letter-length test showed how much players enjoy reading short letters ([[research/narrative/letter-length-test]] [emerging]). The Quiet Lamplighter's letters to Wren already invite a reply ([[world/characters/the-quiet-lamplighter]]).

## Open Questions

- **Word count.** Every phrase choice adds script words, and letters are already 58% of the script ([[research/narrative/script-word-count]] [emerging]).
- **Localization.** Phrases that combine into sentences are hard to translate into Spanish and German ([[decisions/product/PDR-P014-launch-languages|PDR-P014]], [[research/localization/localization-cost-estimate]] [emerging]).
- **Tooling.** It would need a new format in the plain-text script files ([[decisions/technical/ADR-T003-plain-text-dialogue-files|ADR-T003]]).
- **Budget.** Player-written letters should still respect the [[concepts/letter-budget]].
