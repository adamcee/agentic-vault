# Hollowmere World Canon

`world/` holds settled canon for Night Post: places, factions, characters, and history that the script and art must agree with. If a script file, letter, or design doc contradicts a file here, this folder wins until Ines Okafor changes it.

## How Lore Enters This Folder

AI-written lore never lands here directly. It waits in `drafts/` until Ines reviews it against this folder and the [[vault-guide/style-guides/ai-writing-discipline-core]], then moves the parts she approves.

- **Example of a held draft:** [[drafts/ai-lore-hushfolk-expansion]] says the Hushfolk can lie. Canon says they never lie ([[world/factions/the-hushfolk]]), so the draft stays in `drafts/` until a human fixes it.
- **Who approves:** Ines owns canon. Tomas and Priya flag conflicts they find in script or art, and Ines settles them here.

## Canon Rules That Bind the Script

- **No villain.** Every conflict comes from an unpaid debt or an old grudge, and every side has a reason ([[decisions/product/PDR-P001-letters-are-the-quests|PDR-P001]]).
- **Night only.** The forest's paths connect the villages only after dark, so every scene is a night scene ([[ideas/full-day-night-cycle]] was rejected).
- **Hushfolk never lie.** They can refuse to answer or answer narrowly, but every statement they make is true.
- **Nobody dies on Wren's watch.** Danger in the present is social or spatial, never lethal ([[architecture/CONSTITUTION]] P1). Deaths in the past are allowed.
- **Letters stay short.** In-world letters follow the [[concepts/letter-budget]].
