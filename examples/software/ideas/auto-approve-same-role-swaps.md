# Auto-Approve Same-Role Swaps That Add No Overtime

Brigade could approve a [[concepts/shift-swap]] automatically when both people hold the shift's role and the swap adds no overtime, and send every other swap to the manager. Pilot managers approved all 51 same-role swaps in the first two weeks ([[research/pilot-usage-weeks-1-2]] [emerging]).

If adopted, this would supersede [[decisions/product/PDR-P002-manager-approval-for-swaps|PDR-P002]]. A per-location setting would let a manager who wants full control keep it.
