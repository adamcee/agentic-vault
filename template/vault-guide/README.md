# Vault Guide

These pages explain how the vault works and why: the design rationale, the canonical protocol pages, and the style guides for all vault writing. When a protocol summary in [[AGENTS]] differs from its page here, the page wins.

- [[vault-guide/vault-design-philosophy|vault-design-philosophy]]: why the vault is structured this way, with a summary table of every protocol.

## Protocols

- [[vault-guide/decision-propagation-protocol|decision-propagation-protocol]]: review a new decision in chat, then push it into the plan, invariants, and master file.
- [[vault-guide/reweave-protocol|reweave-protocol]]: check existing decisions against new information and record each verdict.
- [[vault-guide/research-traceability|research-traceability]]: link empirical claims to vault research docs and tag their maturity.
- [[vault-guide/wikilink-discipline|wikilink-discipline]]: link references to their canonical docs and verify every target.
- [[vault-guide/ingestion-gate|ingestion-gate]]: stage AI content in `drafts/` and promote it only after the checklist passes.
- [[vault-guide/implementation-plan-triage|implementation-plan-triage]]: close done and stale tasks in the ledger without reprioritizing.
- [[vault-guide/vault-review-protocol|vault-review-protocol]]: audit the vault on six dimensions and route findings to the ledger.
- [[vault-guide/research-paper-workflow|research-paper-workflow]]: bring external sources in through a reference manager, literature notes, and select full texts.
- [[vault-guide/session-logs|session-logs]]: append each session to the history file and the weekly log.
