# Example Vaults

Two example vaults show the method in real projects. Each is its own repository, so you can browse it as a website or clone it and open the folder in Obsidian, the way you would your own vault.

## Night Post

Night Post is a fictional indie RPG about a courier who delivers letters at night through a forest whose paths shift with the moon. Its vault covers six months of a three-person team's work: decisions that changed after playtests, market and accessibility research, a world bible, and the agents' session logs.

[Explore Night Post](https://adamcee.github.io/night-post-vault/){ .md-button .md-button--primary } [View the repo](https://github.com/adamcee/night-post-vault){ .md-button }

## Curbside Cycles

Curbside Cycles is a fictional one-person bike-repair van that comes to commuters at work, showing the method on a business with no software in it. Its vault covers five weeks: a survey, a one-month pilot that changed the pricing, and a rejected storefront lease.

[Explore Curbside Cycles](https://adamcee.github.io/curbside-cycles-vault/){ .md-button .md-button--primary } [View the repo](https://github.com/adamcee/curbside-cycles-vault){ .md-button }
